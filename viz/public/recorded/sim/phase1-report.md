## Wash-trading sweep (SPEC §9)

16 active spores, 3 honest jobs per spore per epoch. Grid: attacker spores 1-3, fee_bps [50, 100, 200], K [50, 100, 200, 500] milliNEAR, gain [500000, 1000000, 2000000], loop volume [10, 50, 200, 1000, 5000] milliNEAR per edge per epoch; seeds [1, 2, 3], 40 epochs, metrics over the second half, worst case over seeds. The attacker's spores only trade with each other.

- **Gate**: attacker net < 0 (rebates minus fees) AND the attacker's best spore stays below the honest median reputation (R ratio < 1). Gated over K within ½×–2× of the variant's default, the same range as fee and gain; other K values are reported.
- **§9 literal**: attacker net < 0 AND attacker tube gain per NEAR < honest AND attacker reputation per NEAR < honest (ratio columns are attacker / honest; NEAR = fees minus rebates on the group's own edges).
